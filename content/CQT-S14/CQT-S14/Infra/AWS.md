# AWS Console

AWS has a web console (like a control panel) at `console.aws.amazon.com` where you can manage all your machines. If you log in there, you can do things like:

- See all running instances
- **Access a machine directly via browser** (called "EC2 Instance Connect" or "Session Manager") — bypassing SSH keys entirely
- Reset/add SSH keys to a machine
