## What was built

### 1. Notebook: Qiskit circuits correctly exported to OpenQASM3

Roman first built **Qiskit** circuits with mid-circuit measurement and `if_test` feedback, then exported the supported examples to OpenQASM 3. The notebook explored teleportation and a three-data-qubit repetition code. The remarkable finding there was that Qiskit's special `MidCircuitMeasure()` instruction failed this export; an ordinary `qc.measure()` placed mid-circuit worked.

### 2. Qibo fork: add a first conditional-gate & export to\_qasm() prototype

In CQT-qibo, he added:

- A first prototype of a measurement-dependent gate like `gates.Condition(register_name, value, gate)`
- Changed `Circuit.add()` to retain collapsing measurements by returning `(MeasurementResult, register_name)`
- Added a function `Circuit.to_qasm3()` to output in QASM3 the dynamic circuit including the measurement-dependent gate.

```py
from qibo import Circuit, gates
from qibo.measurements import MeasurementResult
import qiskit.qasm2


# Build the circuit
circuit = Circuit(1, density_matrix=True)
# Add some gates
circuit.add(gates.H(0))
output, register_name = circuit.add(gates.M(0, collapse=True))
circuit.add(gates.Condition(register_name, 1, gates.X(0)))
circuit.add(gates.H(0))

circuit.add(gates.M(0))

print(circuit.to_qasm3())

# Execute the circuit and obtain the final state
result = circuit(nshots=100) # circuit.execute(initial_state) also works

print(circuit.to_qasm())

```

Roman's `Condition` accepted the register's **name** so the exporter could write an `if (register == value)` comparison. Sergi later linked conditions directly to measurement-result objects. Roman's exporter used only the first measured bit and first gate target. His prototype had no `else`, switch, Boolean expressions, or multi-gate branch.

## Why it mattered

The notebook established **Qiskit → OpenQASM 3** for dynamic circuits. The fork prototype began the separate **Qibo → OpenQASM 3** route that we expanded on.
