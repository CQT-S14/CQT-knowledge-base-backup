# 5. GitHub Pages: publish a getting-started guide

## What was built

After the API and hardware demonstrations, Elis published a small **GitHub Pages guide** from the repository's `docs/` directory. Its content is in `docs/index.md`; `docs/_config.yml` selects the Cayman theme. It gives readers a practical, simulation-level entry point to the conditional-operations API on the `CQT-qibo` fork's `develop` branch.

The guide defines the vocabulary—mid-circuit measurement, measurement result, condition, branch body, `IfElse`, `Switch`, and the `IfChain` builder—then walks through a one-qubit fast reset and a two-bit switch. It explains bit ordering, explicit switch defaults, combining conditions, and running the examples with Qibo's NumPy backend.

## Why it mattered

The public-facing material starts with **how to write and understand conditional circuits**, while the hardware notebook retains the cluster-specific conversion, placement, and execution details. A new teammate can learn the API without first learning Slurm, QuAM, or QUA.

**Limitation:** The page's examples are **simulation examples**. They do not claim that the ordinary Qibo/QiboLab execution route supports these conditionals on NQCH. Hardware execution is only supported right now through Arthur's provider.
