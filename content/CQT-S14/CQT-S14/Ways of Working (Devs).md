# What this is

The “Ways of Working” is intended to be a practical approach we follow in order to develop with:

- **Reproducibility**: anyone can set up the same working environment from scratch in less than a minute.
- **Transparency**: every dependency and its version is recorded and version-controlled.
- **Alignment**: when someone merges a fix, everyone can get it in their environment by simply pulling.
- **Traceability**: all changes go through GitHub, so we always know what changed, when, and why.

> [!TIP]
> *“ If you want to go fast walk alone, if you want to go far walk together”*
>
> *-African proverb*

For efficient and sustainable collaboration we need every team member to ***always*** be able to run the exact same code with the exact same dependencies without surprises.

- No "it works on my account"
- No mystery package versions.
- No manual installs that nobody else knows about.

> [!CAUTION]
> These are strictly forbidden for the sake of reproducibility and collaboration
